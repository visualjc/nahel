Approved design direction (Jim, 2026-07-28, plan item a22spcmj): dispatch passes task context through handoff DOCUMENTS in the run directory, not giant prompts — dispatcher writes nahel/runs/<id>/task.md, the spawned prompt shrinks to a pointer (nahel brief, read task.md, write result.md), journal records paths not content. Mimics the handoff skill's four principles: tailor to the next agent's task, suggested-skills section (-> nahel workflow pointers), reference-dont-duplicate (point at items/PRDs/git refs — the prompt-size fix), redact secrets. Provenance caution: task.md is agent-written, never human-signed unless a human wrote it. Grill before PRD.
