The AFK loop hits host-environment walls that look like agent failures but are not. A Codex dispatch died before worker initialization because the host sandbox made ~/.codex read-only and blocked app-server initialization — no worker action, no code change. Separately, a verified Decision Digest branch could not open its required draft PR because host policy rejected 'git push -u origin epic/decision-digest': the remote was not explicitly trusted for export. Both correctly parked the run rather than working around the gate; both needed a human to widen the environment.
