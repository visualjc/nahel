A user (or an agent acting as product owner) can create and extend product and feature roadmaps through an interviewing partner: it grills, fires off research, kicks off prototypes, comes back with findings, and makes delegated judgment calls — and the user can say 'that is enough to start' at any point without the plan being fully de-fogged.
