An AFK run cannot dispatch a worker when nahel/config carries neither routing.implementation nor routing.default: the workflow forbids bypassing the gate, so every dependency-ready leaf parks instead. This blocked the Decision Digest run's first wave outright — no worker spawned, no PR opened — until a human selected Codex, after which routing recorded agent=codex (the schema permits omitting the model, falling back to the CLI default) and the leaves unblocked. Choosing the implementation agent is a human act the AFK loop cannot make for itself.
